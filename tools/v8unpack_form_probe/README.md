# Пробник обычной формы

Одна команда создаёт временную файловую базу с одной обычной формой,
выгружает CF через `v8unpack 1.2.9` и выполняет три независимых изменения:
заменяет обработчик `ПриОткрытии`, переименовывает реквизит и связывает
элемент с реквизитом. Каждая копия собирается в CF, загружается платформой и
повторно выгружается. Форма с изменённым обработчиком запускается внутри
`xpra`, а журнал подтверждает его фактический вызов:

Тот же исходный CF содержит минимальную управляемую форму. Проверка
`verify.py` сопоставляет её XML и JSON по обработчику, команде, реквизиту и
пути данных.

```bash
./tools/v8unpack_form_probe/run.sh
```

Результат и все промежуточные файлы сохраняются в
`.artifacts/v8unpack-form-probe/run.*/`, включая исходное и изменённое
JSON-деревья и `events.jsonl` с фактическим вызовом. Пути к платформе и
`v8unpack` при необходимости переопределяются через `ONEC_BIN_DIR` и
`V8UNPACK`.
