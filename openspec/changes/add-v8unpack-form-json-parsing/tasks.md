  XML штатным экспортом платформы и JSON точной версией производителя.
- [ ] 1.2 Создать отдельный платформенный пробник обычных `Form.bin`:
  одноразовая файловая база из того же CF, инструментированная копия модулей,
  зафиксированные действия и канонический журнал реально вызванных
  обработчиков, элементов, путей данных, команд и реквизитов.
- [ ] 1.3 Зафиксировать доказанные контракты корневой пары `1.2.9/802`,
  локальных версий форм `5/7/9/12/13` и всех пятнадцати семейств живого
  инвентаря, включая обработчики формы/элементов, команды, обычные и основные
  атрибуты, динамический список, пустую форму и форму без модуля.
- [ ] 1.4 Расширить существующий `v8unpack_oracle` автономно проверяемыми
  манифестами с SHA-256 CF, пробника, входных деревьев и журнала, точными
  командами, версиями, покрытием и мультимножествами `form_elements`.
- [ ] 1.5 Проверить нулевую XML↔JSON-дельту управляемых форм и нулевую дельту
  обычных форм против платформенного пробника; отклонять связь
  событие/обработчик без фактического вызова в журнале.
- [ ] 1.6 Добавить отрицательные проверки неизвестной версии, тега,
  позиционной формы, повреждённого или превышающего 16 МиБ обязательного JSON,
  символьной ссылки и выхода из корня.

## 2. Сборщик и индекс

- [ ] 2.1 Реализовать закрытую матрицу пятнадцати пар семейство/каталог из

  существующим `read_v8unpack_json`.
- [ ] 2.2 Реализовать форматный JSON-декодер обработчиков, команд и атрибутов,
  возвращающий существующие 14-полевые строки `_FORM_ELEMENTS_INSERT` и одну
  служебную строку `kind="form"` только после выбора поддержанного контракта и
  чтения обязательной тройки.
- [ ] 2.3 Добавить `v8unpack_form_status`, четыре форменных счётчика,
  `v8unpack_form_unproven_fragments` и ограниченную
  `v8unpack_form_diagnostics_json`; проверить инвариант
  `total = indexed + failed + unsupported` и отсутствие тихо отброшенных
  неизвестных фрагментов.
- [ ] 2.4 Подключить один JSON-сборщик к полной сборке и каждому `update`
  v8unpack; полностью заменять `form_elements` под точкой сохранения и

- [ ] 2.5 На индексном пути научить `_group_form_rows` обрабатывать маркер

- [ ] 2.6 Повысить `BUILDER_VERSION` и проверить штатную перестройку индекса
