## Why

Формы `v8unpack` представлены обязательной JSON-тройкой `*Form.json`,
`*Form.elem.json`, `*Form.id.json` и необязательным `*Form.obj.bsl`, но текущий
индекс их не разбирает. Поэтому `parse_form()` безопасно возвращает `[]`, хотя
форма и её структура существуют.

## What Changes

- Добавить версионно подтверждённый разбор JSON обычных форм `v8unpack`.
- Заполнять существующую таблицу `form_elements` обработчиками, командами и
  атрибутами формы без изменения публичного контракта `parse_form()`.
- Связывать результат с `*Form.obj.bsl` через `module_path`, когда модуль
  существует; отсутствие модуля не исключает форму.
- Обеспечить паритет полной и инкрементальной индексации форм.
- Добавить воспроизводимый дифференциальный пробник обычных `Form.bin`:
  контролируемо менять по одному известному свойству формы в одноразовой
  конфигурации, преобразовывать результат точной версией `v8unpack` и
  связывать изменившиеся позиции JSON с семантикой 1С. Запуск клиента нужен
  отдельно только для подтверждения фактических связей
  «действие/событие → обработчик» и выполняется внутри `xpra`.
- Сохранять частичный результат и диагностику для неизвестных элементов вместо
  угадывания структуры или падения всего объекта.
- Сохранить поведение разбора форм CF/EDT; исправить распознавание штатного
  тега CF `MainAttribute`, необходимое для точного XML↔JSON-оракула. Не
  добавлять универсальный JSON-декодер.

## Capabilities

### New Capabilities

- `v8unpack-form-json`: Индексация структуры форм `v8unpack` из обязательной
  JSON-тройки с выдачей через существующий `parse_form()`.

### Modified Capabilities

- `v8unpack-form-helper-fallback`: Пустой безопасный результат остаётся только
  запасным поведением, когда подтверждённых строк формы действительно нет.

## Impact

Затрагиваются JSON-адаптер `v8unpack`, сборка и обновление `form_elements`,
`parse_form()`, сведения о полноте индекса, проверочный XML↔JSON-оракул, тесты
форм, платформенный пробник и документация. Потребуется повышение
`BUILDER_VERSION`, чтобы старые
индексы с пустой таблицей форм перестроились. Новые зависимости не требуются.
