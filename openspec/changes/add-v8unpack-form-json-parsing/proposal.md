## Why

Формы `v8unpack` представлены файлами `*Form.json` и `*Form.elem.json`, но
текущий индекс их не разбирает. Поэтому `parse_form()` безопасно возвращает
`[]`, хотя форма, её элементы, команды, обработчики и BSL-модуль существуют.

## What Changes

- Добавить версионно подтверждённый разбор JSON обычных форм `v8unpack`.
- Заполнять существующую таблицу `form_elements` обработчиками, командами и
  атрибутами формы без изменения публичного контракта `parse_form()`.
- Связывать результат с существующим `*Form.obj.bsl` через `module_path`.
- Обеспечить паритет полной и инкрементальной индексации форм.
- Сохранять частичный результат и диагностику для неизвестных элементов вместо
  угадывания структуры или падения всего объекта.
- Не менять разбор форм CF/EDT и не добавлять универсальный JSON-декодер.

## Capabilities

### New Capabilities

- `v8unpack-form-json`: Индексация структуры обычных форм `v8unpack` из
  `*Form.json` и `*Form.elem.json` с выдачей через существующий `parse_form()`.

### Modified Capabilities

- `v8unpack-form-helper-fallback`: Пустой безопасный результат остаётся только
  запасным поведением, когда подтверждённых строк формы действительно нет.

## Impact

Затрагиваются JSON-адаптер `v8unpack`, сборка и обновление `form_elements`,
`parse_form()`, сведения о полноте индекса, проверочный XML↔JSON-оракул, тесты
форм и документация. Потребуется повышение `BUILDER_VERSION`, чтобы старые
индексы с пустой таблицей форм перестроились. Новые зависимости не требуются.
