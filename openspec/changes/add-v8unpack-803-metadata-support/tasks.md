## 1. Проверочный контракт 803

- [x] 1.1 Для каждой независимой пары получить XML и JSON из одного CF и
  сохранить репозиторный манифест: SHA-256 CF, команды, версию платформы,
  маркер и SHA-256 `v8unpack`, корневую и встреченные версии владельцев,
  сводки `total/unique/duplicate`, SHA-256 канонических списков, покрытие,
  состояние, счётчики и точные диагностики. Добавить `xml_input_tree_sha256` и
  `json_input_tree_sha256`: SHA-256 канонически отсортированных
  `(relative_path, content_sha256)` точного набора прочитанных файлов, без
  абсолютных путей и mtime.
- [x] 1.2 Набором независимых пар покрыть реальными объектами все шесть
  структурных семейств. Для `Catalog`, `Document` и
  `ChartOfCharacteristicType` требовать непустые `Attribute` и
  `TabularSection.Attribute`; для `InformationRegister`,
  `AccumulationRegister` и отсутствующего в `demo` `AccountingRegister` —
  непустые `Dimension`, `Resource` и `Attribute`. Результаты разных CF не
  объединять при сравнении.
- [x] 1.3 Сравнить пути `header`, UUID-теги, позиции `GeneratedType/TypeId`,
  дескрипторы элементов и встроенные UUID типов 802↔803; зафиксировать только
  доказанные различия. Для каждой разрешённой записи
  `GENERATED_TYPE_ID_POSITIONS` и `BUILTIN_TYPE_UUIDS` требовать реальный
  парный пример 803 с покрытием `(kind, position, type_form)` или UUID;
  непокрытую запись не включать в контракт.
- [x] 1.4 Добавить репозиторный сравнитель и по каждой паре получить нулевую
  дельту канонически отсортированных мультимножеств фиксированных проекций с
  равенством `Counter`: `object_attributes` без `source_file`,
  `object_synonyms` без `file`, `metadata_references` без `path/line`,
  `metadata_objects` и `metadata_type_ids` без `source_file`; пути JSON и
  `line=NULL` проверить отдельно. Сохранить детерминированный машинно-читаемый
  отчёт с `schema_version`, `comparator_version` и SHA-256 канонического
  содержимого, покрытие примитивных, ссылочных, составных типов, реквизитов
  табличных частей и всех разрешённых записей версионных таблиц; сохранять
  кратность строк и отклонять непокрытые разрешённые записи.
- [x] 1.5 Разобрать расхождение
  `InformationRegister.Характеристики.Resource.Значение` точным тестом:
  для 803 ожидаются `attr_type='[]'`, отсутствие `metadata_references` этой
  строки и отсутствие новой диагностики; исправление XML `TypeSet` не включать.

  `unsupported_object_version`, добавить его в закрытую таблицу кодов/ролей и

- [x] 2.7 Не менять белый список файлов, пользовательские таблицы и пути
