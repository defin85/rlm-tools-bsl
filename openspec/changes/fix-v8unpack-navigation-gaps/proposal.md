## Why

Выбранный корень исходников может намеренно находиться под
`.gitignore`: основной индекс при этом строится, но `git_search` молча не видит
BSL/JSON-файлы. Одновременно `parse_form()` на `v8unpack` без индексированных
элементов форм принимает диагностическую подсказку навигации за путь и
завершается `FileNotFoundError`.

## What Changes

- Полнотекстовый поиск охватывает все читаемые обычные файлы внутри явно
  выбранного корня, включая исключённые из Git, кроме внутренних данных
  `.git`, и сохраняет текущие фильтры, ограничения и защиту путей.
- Существующий `git grep` остаётся поисковым движком, но запускается в режиме
  файлового дерева выбранного корня без применения `.gitignore`.
- `parse_form()` для `v8unpack` без поддерживаемого представления формы
  возвращает пустой результат, а не пытается читать диагностическую подсказку
  как файл.
- Добавляются регрессионные проверки на полностью исключённый из Git корень и
  на форму `v8unpack`.
- Разбор `DocumentForm.json`/`*.elem.json` и индексирование элементов форм в
  этот change не входят.

## Capabilities

### New Capabilities

- `ignored-source-full-text-search`: Полнотекстовый поиск по выбранному корню
  внутри Git-репозитория независимо от состояния отслеживания и `.gitignore`.
- `v8unpack-form-helper-fallback`: Безопасное поведение `parse_form()` для
  `v8unpack`, пока структурный разбор JSON-форм не поддерживается.

### Modified Capabilities

Отсутствуют.

## Impact

Затрагиваются реализация и регистрация `git_search`, используемый `safe_grep`
общий поисковый движок, файловая навигация
`parse_form()`, их тесты и документация по границам поиска. Публичные сигнатуры,
формат индекса, версия построителя и зависимости пакета не меняются.
