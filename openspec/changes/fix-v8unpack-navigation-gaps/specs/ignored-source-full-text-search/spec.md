## ADDED Requirements

### Requirement: Полнота поиска выбранного корня
Для выбранного корня внутри рабочего дерева Git `git_search` SHALL искать все
читаемые обычные текстовые файлы внутри этого корня, кроме внутренних данных
`.git`, независимо от состояния отслеживания и правил `.gitignore`.

#### Scenario: Полностью исключённый корень
- **WHEN** зарегистрированный корень целиком исключён родительским `.gitignore`
  и содержит BSL- и JSON-файлы с искомой строкой
- **THEN** `git_search` возвращает совпадения из обоих типов файлов

#### Scenario: Смешанное состояние файлов
- **WHEN** корень содержит отслеживаемые, обычные неотслеживаемые и
  игнорируемые текстовые файлы
- **THEN** совпадения возвращаются для всех трёх состояний без дубликатов

#### Scenario: Скрытый игнорируемый файл
- **WHEN** скрытый текстовый файл внутри выбранного корня исключён через
  `.gitignore` и содержит искомую строку
- **THEN** `git_search` возвращает совпадение, поскольку выбранный корень
  является явной границей поиска

#### Scenario: Корень вне репозитория
- **WHEN** выбранный корень не принадлежит Git-репозиторию
- **THEN** автоматическая регистрация сохраняет прежнее поведение и не
  добавляет `git_search`

#### Scenario: Git недоступен
- **WHEN** исполняемый файл Git недоступен
- **THEN** `git_search` не регистрируется, а существующие файловые хелперы
  продолжают работать

### Requirement: Сохранение границ и фильтров поиска
Файловый полнотекстовый поиск SHALL оставаться внутри выбранного корня и SHALL
сохранять текущую семантику `path`, `file_types`, `exclude_path`, `regex`,
`ignore_case`, `mode`, ограничений результата, исключения двоичных файлов и
тайм-аута.

#### Scenario: Ограничение типом файла
- **WHEN** одна строка встречается в BSL и JSON, а передан
  `file_types="json"`
- **THEN** результат содержит только JSON-файлы

#### Scenario: Ограничение поддеревом
- **WHEN** передан безопасный относительный `path`
- **THEN** поиск возвращает совпадения только из этого поддерева

#### Scenario: Небезопасный путь
- **WHEN** передан абсолютный путь, выход через `..` или pathspec с расширяющей
  маской
- **THEN** `git_search` возвращает структурированную ошибку и не расширяет
  область поиска

#### Scenario: Внутренние данные Git
- **WHEN** внутри выбранного корня присутствует каталог или файл `.git` с
  искомой строкой
- **THEN** содержимое `.git` не попадает в результаты

#### Scenario: Символьная ссылка наружу
- **WHEN** внутри выбранного корня находится символьная ссылка на каталог за
  его пределами, содержащий искомую строку
- **THEN** внешний каталог не обходится и его содержимое не попадает в результат

### Requirement: Ограничение выдачи и времени файлового поиска
Полнотекстовый поиск SHALL применять существующий тайм-аут при обходе
игнорируемого дерева, SHALL ограничивать возвращаемые записи через
`max_results` и SHALL обозначать усечение результата по действующему контракту.
`max_results` не является обещанием потокового ограничения памяти или вывода
дочернего процесса.

#### Scenario: Число совпадений превышает предел
- **WHEN** игнорируемое дерево содержит больше совпадений, чем `max_results`
- **THEN** выдача ограничена и содержит признак усечения

#### Scenario: Поиск превышает тайм-аут
- **WHEN** файловый поиск не завершается за настроенный тайм-аут
- **THEN** `git_search` возвращает структурированную ошибку, а не пустой список

### Requirement: Паритет литерального safe_grep
Переход общего `_git_grep()` в файловый режим SHALL сохранять результат
литерального быстрого пути `safe_grep` для переданного точного списка BSL-файлов
и SHALL сохранять существующий Python-fallback при отказе поискового процесса.

#### Scenario: Точный список BSL-файлов
- **WHEN** `safe_grep` передаёт `literal_files` с отслеживаемыми и
  игнорируемыми BSL-файлами
- **THEN** быстрый путь возвращает те же строки, номера и POSIX-пути, что
  файловый Python-путь, без совпадений из других файлов

#### Scenario: Отказ файлового движка
- **WHEN** общий вызов `git grep` завершается ошибкой
- **THEN** `safe_grep` выполняет существующий Python-fallback по тем же
  кандидатам
