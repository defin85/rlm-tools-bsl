## ADDED Requirements

### Requirement: Безопасный результат для форм v8unpack
`parse_form()` SHALL возвращать пустой список для источника `v8unpack`, если
индекс не содержит элементов запрошенной формы, и SHALL NOT применять к такому
источнику эвристики путей CF/EDT.

#### Scenario: Форма документа v8unpack
- **WHEN** источник `v8unpack` содержит модуль
  `Document/<Объект>/DocumentForm/<Форма>/DocumentForm.obj.bsl`, но элементы
  формы не индексированы
- **THEN** `parse_form("<Объект>")` возвращает `[]` без исключения

#### Scenario: Диагностическая подсказка навигации
- **WHEN** поиск файла формы возвращает диагностическую подсказку о совпавшем
  каталоге вместо файла
- **THEN** `parse_form()` отбрасывает элемент, не передаёт подсказку в чтение
  файла и не завершает работу с `FileNotFoundError`

### Requirement: Приоритет индексированных элементов формы
`parse_form()` SHALL сохранять существующий индексный быстрый путь: если для
объекта `v8unpack` доступны строки элементов формы, они SHALL группироваться и
возвращаться до применения безопасного пустого результата.

#### Scenario: Элементы формы доступны в индексе
- **WHEN** индекс содержит элементы формы для запрошенного объекта `v8unpack`
- **THEN** `parse_form()` возвращает сгруппированные обработчики, команды и
  атрибуты по существующему контракту

### Requirement: Совместимость CF и EDT
Исправление SHALL сохранять существующий индексный и файловый разбор форм
источников CF и EDT.

#### Scenario: Форма CF
- **WHEN** форма представлена как `Forms/<Форма>/Ext/Form.xml`
- **THEN** `parse_form()` возвращает прежнюю структуру формы

#### Scenario: Форма EDT
- **WHEN** форма представлена как поддерживаемый `Form.form`
- **THEN** `parse_form()` возвращает прежнюю структуру формы
